## GOAL:
This project aims to help people personally track the moods they've experienced throughout the day, which may serve as a self-awareness and habit-building tool. Target users may be tired students and busy workers who are constantly dumped with academic/work-related tasks, and even people with emotional issues and psychological illnesses to help them cope, but will not serve as a direct cure.

## FEATURES:
The app's following features are:
   - Add Mood: The user enters a new mood, description, and its intensity
   - Search and View Moods: The user looks up a mood by either its name or ID and sees its history
   - Filter by Date: The user filters moods by the date it was inputted/experienced

## SPECIFIC DATA HANDLED:
   - Add Mood: Mood and intensity records in JSON file
   - Search and View Moods: Mood log entries (date, intensity on that day, etc..)
   - Filter by Date: Date log entries
